Verfügbare Kartensätze:
* Intervalle (→ 3er-Zuordnung)
* Lineare Funktionen (TODO)
* Quadratische Funktionen (→ Gruppenpuzzle, inkl. Gruppeninfo)
* Produktform (Produktform quadratischer Funktionen → 3er-Zuordnung)
* Formen Quadratischer Funktionen (Hauptform, Scheitelform & Produktform → 3er-Zurodnung)
* Potenzfunktionen (Arten von Potenzfunktionen $$f(x) = a\cdot x^n, n\in \mathbb{Q}$$ → Gruppenpuzzle, inkl. Gruppeninfo)
* Exponentialfunktionen (Arten von Exponentialfunktionen → Gruppenpuzzle, inkl. Gruppeninfo)
* Polynomfunktionen I (Globales Verhalten von Polynomfunktionen → 4-Gruppen-Zuordnung)
* Polynomfunktionen II (Symmetrie von Polynomfunktionen)

Der Kartensatz wird über den URL-Parameter ```?set=...``` ausgewählt. Beispiele:
```
https://hfrank03.github.io/kaertchen_ziehen/?set=Intervalle
https://hfrank03.github.io/kaertchen_ziehen/?set=Quadratische%20Funktionen
```

Allen SuS wird anfangs ein individueller Code (z.B. ```A7K``` - nicht vergeben, siehe ```codes.xlsx```) zugeteilt. 
Sie verwenden diesen Code dann dauerhaft, um Kärtchen zu ziehen.
